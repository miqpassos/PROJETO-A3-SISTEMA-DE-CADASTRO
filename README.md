# 🎓 Sistema Acadêmico — Cadastro e Consulta

Projeto acadêmico (A3) desenvolvido em **Python** com o objetivo de gerenciar o cadastro e a consulta de **alunos, professores e cursos**, aplicando conceitos fundamentais de lógica de programação e **Programação Orientada a Objetos (POO)**.

## 🚀 Funcionalidades

- [x] Cadastro de Alunos, Professores e Cursos
- [x] Consulta de informações cadastradas
- [x] Menu interativo em loop contínuo (`while True`) e estruturas condicionais
- [ ] Interface gráfica (GUI) utilizando a biblioteca nativa **Tkinter** *(em desenvolvimento)*

## 🛠️ Tecnologias e Conceitos Aplicados

* **Linguagem:** Python 3
* **Paradigma:** Programação Orientada a Objetos (Classes, Objetos e Métodos)
* **Interface Gráfica:** Tkinter *(em implementação)*
* **Ambiente & Versionamento:** VS Code, Git e GitHub

## 💻 Como executar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/miqpassos/PROJETO-A3-SISTEMA-DE-CADASTRO.git
   ```
2. Acesse a pasta do projeto e execute o arquivo principal no terminal:
   ```bash
   python main.py
   ```
*(Observação: substitua `main.py` pelo nome exato do seu arquivo principal, caso seja diferente).*
